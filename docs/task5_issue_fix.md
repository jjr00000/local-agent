# 工程日志：Issue #1 缺陷修复
## 任务目标
修复项目主程序src/main.py仅输出固定占位文本的问题，实现对接本地Bionic大模型API，支持多轮对话上下文记忆。

## 问题分析
1. 原始主程序没有调用大模型接口，只会打印固定文字；
2. 缺少对话历史保存逻辑，无法记住前面的对话内容；
3. 模块导入路径没有处理，无法导入backend包内的API函数。

## 实现步骤
1. 编写backend/llm_api.py，封装本地127.0.0.1:1234的OpenAI风格接口请求函数；
2. 修改src/main.py，增加sys.path路径处理，实现backend包导入；
3. 增加chat_history列表保存完整对话上下文，每一轮对话把历史全部传给大模型；
4. 增加exit退出指令，实现交互式命令行对话。

## 测试结果
运行 python src/main.py，可输入问题，调用本地大模型返回回答，能记住多轮对话，输入exit正常退出。

## 总结
成功完成接口对接，实现带上下文记忆的本地大模型交互式CLI程序。
