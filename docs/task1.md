# Task1｜本地大模型CLI对话
## 任务目标
在本地通过LM Studio部署GGUF格式大模型，编写命令行CLI交互程序。实现多轮对话上下文记忆，同时支持对话记录保存、读取历史会话。

## 开发进度
1. 环境准备：下载GGUF模型，在LM Studio加载模型，开启本地API服务。
2. 基础接口对接：调用LM Studio本地接口，完成大模型基础问答。
3. 实现对话上下文，模型可以记住前面的聊天内容。
4. 增加会话持久化功能，将对话记录保存到本地文件，支持读取历史对话。

## 遇到的问题 & 解决方案
1. **KeyError: 'choices'**
现象：程序运行抛出该报错，拿不到模型返回内容。
原因：LM Studio服务未启动，或者代码内填写的模型名称和LM Studio加载的模型不一致。
解决：先确认LM Studio模型加载完成并打开Local Server，核对代码里模型名称。

2. API连接超时
现象：请求一直卡住，无法收到回复。
原因：端口不对，或者防火墙拦截本地1234端口。
解决：确认LM Studio默认端口1234，关闭占用端口程序。

## 思考总结
LM Studio兼容OpenAI接口格式，迁移代码很方便。会话持久化适合做智能体，保留历史对话。本地大模型不用联网，完全离线运行，缺点是推理速度受电脑硬件限制。
